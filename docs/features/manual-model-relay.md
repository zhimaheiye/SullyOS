# 手动外部模型接力

设置页版本信息下可持续开启或关闭。开启后，合格的前台文字生成冻结完整请求，用户手动复制至自己有权使用的外部模型，再粘贴一次完整结果；原应用继续解析原有文本、JSON 或 HTML。接力文本只保存在当前内存；开关偏好单独保存在本机。

不登录或自动操作外部网站，不提供账号 CLI。请求必须由当前应用近期真实操作触发；多模态、原生工具和结构不受支持的请求明确停止，不偷偷发真实模型请求。粘贴回复禁止触发工具/网络控制标签。切应用、角色、页面隐藏、超时、取消会使当前请求失效；接力后的自动追加生成被阻止。后台任务不抢占前台接力。

主链路是 `utils/manualModelRelay.ts` → `safeApi` / OSContext fetch 边界 → `components/ManualModelRelayPanel.tsx`。云端即时聊天与本机接力不能同时接管同一轮；须明确选择路由。
