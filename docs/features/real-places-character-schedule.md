# 真实地点角色日程

每角色默认关闭，由使用者选择地区和地点类别；学校/工作点可由使用者固定。沿用设备自己的高德 Web 服务 Key，不内置发行方 Key，不读取 GPS 来决定角色区域。

地图查询经仅允许官方固定接口的隔离 iframe 直连高德。候选坐标只在当前设备内用于行政区、类别和隐私圈过滤；隐私圈边缘另留 300 米缓冲。仅认证后的地点 ID、名称、行政区和类别进入日程提示；模型须使用本批候选中的原 ID 与原名。家园房间优先，地图不可用仍可生成普通文字日程，不额外请求一次模型。

隐私设置在查询后变化则丢弃候选。设备 Key、隐私圈中心、精确 POI 坐标不进入提示词、Worker、备份或日程元数据。当前开关、区域及已认证的安全地点信息随角色/日程备份。

主要代码：`utils/scheduleRealPlaces.ts`、`utils/scheduleGenerator.ts`、`components/schedule/RealPlaceScheduleSettings.tsx`。验证只使用合成地图响应，不调用真实地图或付费模型。
