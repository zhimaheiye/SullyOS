# Meta 单角色体验

## 档案信息

- 类型：独立桌面 App 与私聊提示扩展
- 当前状态：开发中，很多功能尚未完成
- 首版日期：2026-11-04

## 当前实现

公开版桌面提供「Meta（开发中）」入口。用户选择一位现有角色后开始一段独立体验，可以进入该角色私聊、查看开始时间与本次重回次数，也可以随时结束。开屏必须直接显示“目前仍在开发中”和“很多功能还不完善”，不能把当前范围描述为完整主线玩法。

运行状态只保存在当前浏览器的 localStorage，记录角色 ID、开始时间和重回次数。私聊请求只追加一段轻量 Meta 语境；重新生成回复时增加一次计数。它不改变角色设定，不新增独立聊天历史、剧情树或长期记忆库。

## 与私人版本的边界

公开实现不依赖私人主线模式、世界线存档或其 token。它不会导入私人剧情、线上任务、账号信息或部署配置。以后扩展玩法时仍应使用公开版自己的状态契约，不把私人模块作为隐式前置条件。
