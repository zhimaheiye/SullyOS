# 临时番外与卡片创作

私聊和群聊「＋」菜单提供番外创作。复用当前角色身份、可见聊天和世界书构造只读上下文，群成员按各自可见窗口读取；输入支持角色/用户名占位符、续写和流式正文。番外是非正史临时文本，关闭后不进入普通消息、记忆或备份；已接入的单次调用诊断按24小时本机限额保留，可在调用记录中删除。截图留白只影响当前呈现，不改原文。

私聊 HTML 卡片创作沿用角色/全局普通 API，读取上下文时不修复或封存时间线；生成结果先预览，只有用户点击发布才保存为 HTML 消息。HTML 沿用现有渲染隔离，不开放工具执行。未完成、取消或报错的生成不写回聊天。

主要代码：`utils/cardCreation.ts`、`utils/sideStoryCreation.ts`、`utils/groupSideStory.ts`、`utils/sideStoryMask.ts` 及对应弹窗。公开版仅支持普通 API 和人工文字接力，不包含本机账号渠道。

## 2026-11-14 独立批量创作

桌面增加番外创作与 HTML 创作，复用公开版现有生成器、只读上下文与普通 API／人工接力，和聊天弹窗分开。按选择的角色串行生成，支持停止、继续、失败单项及全部重试；重试／继续视图仅展示冻结的本轮 ID，旧成功作品仍可在全部结果中查看。切页面或恢复数据中断本批，角色身份／API改变时停止迟到结果。临时作品只在当前页面，不进入备份、聊天或记忆；HTML 可预览和复制，不自动发布。角色锁等待实际请求收尾，避免停止后重叠计费。入口 apps/CreationBatchApp.tsx、utils/creationRunLock.ts。
