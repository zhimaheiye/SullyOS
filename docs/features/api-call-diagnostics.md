# API 单次调用诊断

2026-11-14 按本次明确授权迁入公开版，扩展原设置中的 API 调用记录。

## 行为与隐私

已接入调用的成功、失败及“传输完成”诊断自动在本机滚动保留24小时，取消不留正文。单次可删除，清空调用记录同时清除诊断并阻止在途旧结果重新写入。完整备份与纯文字备份不包含 api_call_log；一次性抓包沿原独立入口。

请求、响应、提取正文各最多49,152字符；超过上限省略并注明。落盘最多40条／4 MiB，内存24条／2 MiB，待写8条，活动证据最多20分钟。容量和写入失败可使内容提前不可用。关闭应用期间不能物理清理，到期后下次诊断读写清理。密钥、鉴权、链接、媒体编码和受保护定位字段过滤；内容仍可能包含聊天、记忆和角色资料，不等于可随意对外分享的脱敏报告。

## 覆盖边界

- safeFetchJson 文字 HTTP 与 SSE、completeTextTask 及主聊天正文；主聊天工具轮与正式保存有业务结算。
- 群聊普通导演／成员经 MCP completion 使用共享传输；未接业务回执的记录只标“传输完成”，不冒充解析或保存成功。
- 番外／HTML 与独立批量创作允许在专用诊断中保存暂态内容；格式校验和批次更新分别结算。
- Anthropic 在协议转换后记录请求，响应标为适配层。透明流式升级保留已消费的原始分片和结束标记证据；SSE 内嵌错误按失败处理，保留实际外层 HTTP 状态。
- 裸 fetch 旁路、手动外部模型接力、云 Worker 原文、显式视觉和未接入暂态链路不覆盖。本次没有迁入本机账号 CLI、私人生活代理或它们的诊断同步。

主要文件：utils/apiCallDiagnostics.ts、utils/safeApi.ts、utils/anthropicApi.ts、utils/streamUpgrade.ts、utils/db.ts、components/settings/ApiCallLogModal.tsx。五日摘要继续独立，不把历史摘要当作可恢复正文。
