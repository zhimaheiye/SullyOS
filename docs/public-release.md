## 保留与本次更新

- README 功能表中列出的桌面 App，普通 API 对话、用户自行配置的主动消息、MCP、识图、上传图片与语音。
- 私聊/群聊临时番外创作、续写和截图文字留白；HTML 卡片创作经用户明确发布才进入聊天。
- 持续手动外部模型接力：复制完整文字请求、人工粘贴单次完整回复；不接入账号 CLI，不自动操作模型网站，不运行工具。
- 人生重映小说、视觉小说、见面立绘三种阅读模式；建议选项先填入可编辑输入框。
- 世界书按角色暂停/恢复分组；七套白盒预设；聊天菜单拖拽分页、逐条转发与返回桌面规则。
- 四项独立副 API：角色情绪、记忆轻量分析、心象翻译、我的日程解析。其它任务保留原 API 来源。
- 默认关闭的真实地点角色日程：自行配置区域与设备地图 Key；隐私圈、精确坐标和 Key 不进入提示词或备份。
- 剧本杀通用 V2 引擎、JSON 导入校验、主持台、独立对局与备份；发行包不含第三方剧本、原文、改编包或剧透测试。
- 存储恢复、记忆水位、PDF 禁止 eval、相关依赖安全修复与本机主动消息 1.0 残留任务/连续失败处理。

GitHub Pages 工作流由维护者手动触发，产物不启用统计，不携带环境密钥或个人存档。不得使用仓库里遗留的私人 Netlify/Cloudflare 站点配置部署。默认 Git 推送禁用配置保留；每次发布须审核快照后明确指定公开仓库。
