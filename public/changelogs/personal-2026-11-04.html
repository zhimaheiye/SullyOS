Meta 开发中体验

桌面新增 Meta 入口，可以选择一位角色开始单角色体验，并从这里进入聊天、记录本次重回次数。开屏会直接标明这项功能仍在开发中，很多互动还没有完成；后续还会继续补充，目前不会改变原有聊天与存档。

重回前，可以只给这一次补一句方向

对一条回复重新生成时，可以临时告诉角色这次更想看到什么。引导只作用于这一次重回，不会改掉角色设定，也不会变成长期记忆。

先确认图片描述，再继续聊天

聊天中的新图片可以先生成可检查的文字描述；多张图片可以自己选择处理哪些，动图会抽取代表画面。确认后的描述跟着这次聊天使用，原图、旧消息和没有选中的图片不会被悄悄补扫。

把当前角色的聊天写进 Obsidian 日记

聊天输入区新增一键写日记。它会根据当前角色和当前聊天范围整理一篇日记，写入你已经选择的 Obsidian 目标；执行途中切换角色、页面或目标时会停下，避免写错地方。

副 API 可以一次切换一组功能

副 API 管理页增加批量切换，可以挑选多项文字功能，一次改到同一个预设或模型。保存前仍能检查选择，不会顺手改动没有勾选的功能。

时间胶囊按选择顺序逐个邀请

邀请多位角色时，现在会按选择顺序一位一位写入。页面会保留每个人的等待、写入、成功或失败状态；中途停止后可以继续，失败也能单独重试，已经成功的角色不会再次生成。

手动提醒和启动器日历

我的日程和任务工坊补上了手动生活提醒：可以新建、编辑、改期、暂停、恢复、完成或取消，也能关联任务。启动器日历会显示这些由你自己建立的安排。
