最近会话可以手动置顶

私聊和群聊都能置顶或取消。置顶顺序不会被新消息打乱，刷新后继续保留，也会随完整备份带走。

查看一次 API 调用的诊断

设置里的 API 调用记录可以查看已接入请求的输入、响应、结束原因和处理状态。成功与失败诊断自动在本机滚动保留24小时，容量满时可能提前清理，也能手动删除。诊断可能含聊天与角色资料；未接入的调用不会补造原文。

电脑端小宇宙

从电脑本机启动 SullyOS，可以添加节目、关联本机音频和时间戳文稿，切换 App 后继续播放。邀请角色一起听，按实际听过的片段讨论；整理的小结只有明确分享才带回聊天。公开在线网站没有本机接口，扫码和在线文稿需自行配置兼容客户端。

独立批量番外和 HTML 创作

桌面新增两个独立创作入口，可以选择多位角色依次生成。停止后继续，失败单独重试；重试页面只展示本轮角色，之前成功的作品仍保留，可以切回全部查看。作品是临时预览，不会自动发布到聊天或写入记忆。原聊天里的创作弹窗继续保留。
